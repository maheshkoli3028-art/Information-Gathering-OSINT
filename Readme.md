# Information Gathering & OSINT Project

## About the Project
This project demonstrates information gathering and reconnaissance techniques using Kali Linux tools. It focuses on collecting publicly available information and understanding the potential exposure of a domain.

## Objectives
- Understand passive and active reconnaissance.
- Learn basic DNS and domain enumeration.
- Identify publicly available domain and subdomain information.
- Practice using common cybersecurity tools.
- Document findings and observations.

## Tools Used
1. **WHOIS** — Retrieves domain registration information when available.
2. **theHarvester** — Collects publicly available information such as email addresses and hostnames from supported sources.
3. **nslookup** — Queries DNS records.
4. **Google Dorking** — Uses advanced search operators to find publicly indexed information.
5. **Subfinder** — Discovers subdomains using supported passive sources.

## Practical Exercises
- WHOIS Enumeration
- theHarvester Information Collection
- DNS Lookup Using nslookup
- Google Search Operators
- Subdomain Discovery Using Subfinder

## Methodology
1. Define the authorized target and scope.
2. Collect publicly available information.
3. Perform DNS and subdomain enumeration.
4. Record observations and evidence.
5. Review findings and document potential security risks.

## Results
The results depend on the selected domain, available public information, and the data sources used. Screenshots and observations are included in this repository.

## Ethical Considerations
Testing was limited to authorized targets and permitted activities. Public information was handled responsibly, and no unauthorized access was attempted.
